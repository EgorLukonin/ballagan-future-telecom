# Спецификация REST API — Materials Microservice

## 1\. Общая информация

* **Назначение сервиса:** микросервис для получения списка файлов и папок из публичных каталогов Яндекс Диска с поддержкой динамического переопределения ссылок, проверки формата и обработки внешних сетевых ошибок.  
* **Базовый префикс:** `/api/v1/materials`  
* **Формат данных:** `application/json`

## 2\. Эндпоинты

### Получение списка материалов

Возвращает структурированную информацию о содержимом папки Яндекс Диска (название, путь, общее количество элементов и массив файлов/подпапок).

* **URL:** `/list`  
* **Метод:** `GET`

#### **Заголовки (Headers)**

| Название | Тип | Обязательный | Описание |
| :---- | :---- | :---- | :---- |
| `X-Disk-Folder-Link` | `string` | **Нет** | Публичная ссылка на папку Яндекс Диска (`https://disk.yandex...`). Если заголовок не передан, автоматически используется значение по умолчанию (`YANDEX_DISK_PUBLIC_KEY`) из конфигурации сервиса. |

#### **Параметры запроса (Query Parameters)**

| Название | Тип | По умолчанию | Описание |
| :---- | :---- | :---- | :---- |
| `path` | `string` | `"/"` | Путь к подпапке внутри целевого публичного каталога. |

## 3\. Форматы ответов

### Успешный ответ (`200 OK`)

Пример тела ответа при успешном запросе к публичному ресурсу:

{  
  "status": "Успешно",  
  "folder\_info": {  
    "name": "Название папки",  
    "path": "/",  
    "total\_items": 1  
  },  
  "items": \[  
    {  
      "name": "example.txt",  
      "type": "file",  
      "size": 128,  
      "mime\_type": "text/plain",  
      "file": "https\://downloader.disk.yandex.ru/disk/..."  
    }  
  \]  
}

## 4\. Коды ошибок и обработка исключений

Микросервис возвращает стандартизированные HTTP-статусы с понятным описанием в поле `detail`:

| Код ошибки | Описание ситуации | Пример тела ответа |
| :---- | :---- | :---- |
| **`401 Unauthorized`** | Ссылка на Яндекс Диск не указана, отсутствует или имеет некорректный формат (не начинается с `https://disk.yandex`). | `{"detail": "Не указана или некорректна ссылка на папку Яндекс Диска."}` |
| **`404 Not Found`** | Запрошенная папка или файл не существуют на Яндекс Диске (внешний API вернул 404). | `{"detail": "Папка не найдена или нет доступа"}` |
| **`503 Service Unavailable`** | Произошла сетевая ошибка при попытке обращения к API Яндекс Диска либо внешний API вернул нештатный код ответа. | `{"detail": "Сервис Яндекс Диска временно недоступен."}` |
